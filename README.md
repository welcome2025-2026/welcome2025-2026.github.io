# Faculty of Computing & Technology - Official Gateway

This repository acts as the **Permanent Redirect Gateway** for the Faculty of Computing & Technology (FCT), University of Kelaniya orientation and student welcome portal.

### Live Permanent Gateway Link:
👉 **https://welcome2025-2026.github.io**

### Maintenance:
To change the destination URL in the future (without re-printing QR codes):
1. Open `index.html`
2. Update the `TARGET_URL` variable to your new destination domain.
3. Commit changes.
